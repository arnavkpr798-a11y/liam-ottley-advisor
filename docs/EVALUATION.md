# Evaluate your advisor

A fluent answer is not evidence of an accurate emulation. This is a suggested evaluation workflow, not a claim that an advisor has passed it.

Prepare 12 original questions from the work you actually do: eight development questions and four held-out final cases. Include a normal decision, a conflicting-source case, an unsupported income claim, a missing-business-input case, an out-of-library topic and an unknown-date case.

For each answer, check:

- Does the cited passage exist and support the attributed claim?
- Is the speaker correctly identified, with uncertainty preserved?
- Are source advice, user facts and AI interpretation kept separate?
- Does the recommendation fit the supplied constraints?
- Are unsupported numbers and promises absent?
- Does it correctly acknowledge missing evidence?
- Is the next action clear and useful?

Save the question, inspected evidence locations, answer and human judgment privately. Fix failures on the development set before using the holdout. Do not let the answering model rewrite expected results or grade itself as ground truth.

If building a decision playbook, each card should record the principle, when it applies, why, an example, exceptions, supporting video/timecodes, speaker attribution, date/unknown and conflicts. Track actual source-review coverage. An index of titles is not a full source study.

Compare versions on the same questions, bound iteration time/cost and retain rollback. Source-grounded usefulness and stylistic similarity are separate criteria.
